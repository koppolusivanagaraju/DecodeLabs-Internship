# Student Management API

## Description

This project was developed as part of the Decode Labs Full Stack Development Internship.

The purpose of this project is to learn backend development by creating a REST API using Node.js and Express.js. The API allows users to manage student records by performing operations such as adding, viewing, updating, and deleting student information.

This project helped me understand how APIs work, how data is sent and received using JSON, and how backend applications handle client requests and responses.

## Features

* Get all student records
* Get a student by ID
* Add a new student
* Update student details
* Delete student records
* Input validation
* HTTP status code handling

## Technologies Used

* JavaScript
* Node.js
* Express.js
* Thunder Client

## API Endpoints

GET /students

GET /students/:id

POST /students

PUT /students/:id

DELETE /students/:id

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required packages:

npm install

4. Start the server:

node server.js

5. Open the browser and visit:

http://localhost:3000/students
